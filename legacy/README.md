# Legacy DenseNet Course Project

This directory archives the original DenseNet course project and preserves its historical structure and artifacts.

- `course_project/OriginalDenseNet` contains the legacy baseline implementation.
- `course_project/Upgraded` contains the legacy Mish and Squeeze-and-Excitation variant.
- `course_project/Results` contains legacy reports, notebooks, and checkpoints.

`Evaluation_Report.ipynb` includes mock and hardcoded metrics and must not be treated as experimental evidence. The checkpoints are unverified legacy artifacts, and historical accuracy values must not be used as official research results.

The new reproducible research project will be developed outside this `legacy` directory. The `legacy-course-project` Git tag preserves the original code snapshot. Checkpoints have also been backed up outside the repository with a SHA-256 manifest.
